# EvoNews

<p align="center">

</p>

A small PHP and MySQL news posting system from the Evolution BB project.

## What it does

- Lets registered users log in and post news items.
- Lists posted news newest first.
- Includes an admin area for managing users and changing passwords.
- Supports more than one language through the `languages` folder.

## Tech

- PHP
- MySQL

## Setup

Set the database details in the `CONF` folder, create the
`news_users` and `news_posted` tables, and serve the folder with PHP.
